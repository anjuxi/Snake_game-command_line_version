# 贪吃蛇游戏（命令行版）

一个基于 C 语言开发的经典贪吃蛇游戏，运行在 Windows 命令行环境中。

## 项目简介

本项目是一个使用 C 语言编写的贪吃蛇游戏，具有完整的游戏逻辑和丰富的功能特性。游戏界面简洁美观，支持多种操作方式和速度调节。

## 功能特点

- ✅ 经典贪吃蛇游戏玩法
- ✅ 支持方向键和 WASD 两种控制方式
- ✅ 长按方向键临时加速功能（2倍速）
- ✅ 实时得分和最高纪录记录（自动保存到文件）
- ✅ 可调节基础游戏速度（+/-键）
- ✅ 暂停/继续功能（P键）
- ✅ 游戏结束界面显示
- ✅ 彩色控制台界面
- ✅ 防止蛇直接掉头的智能控制

## 游戏规则

1. 使用方向键或 WASD 控制蛇的移动方向
2. 吃到 ★ 可以增加蛇的长度和得分（每吃一个得10分）
3. 撞到墙壁或自己的身体游戏结束
4. 按住方向键/WASD 可以临时加速移动
5. 按 P 键暂停游戏，按任意键继续
6. 按 + 键加快基础速度，按 - 键减慢基础速度
7. 按 X 键退出游戏

## 操作说明

| 按键        | 功能              |
| ----------- | ----------------- |
| ↑↓←→ / WASD | 控制蛇的移动方向  |
| 长按方向键  | 临时加速（2倍速） |
| P           | 暂停/继续游戏     |
| + / =       | 加快基础速度      |
| - / _       | 减慢基础速度      |
| X           | 退出游戏          |

## 编译运行

### 编译方式

使用支持 Windows API 的 C 编译器（如 MinGW、MSVC）编译：

```bash
gcc 贪吃蛇（命令行版）.c -o snake.exe -lmsvcrt
```

### 运行方式

直接运行编译生成的可执行文件：

```bash
snake.exe
```

或者双击运行 `a.exe`（已编译好的版本）。
